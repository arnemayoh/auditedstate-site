Lexicon

This is not a glossary. It is a structured map of how understanding is formed, lost, and preserved.

Coming from other domains?

If you are familiar with terms like Hybrid Intelligence, Human-in-the-loop, or Knowledge Management, see our Semantic Bridges to see how these concepts map onto the PKOS framework.

Concepts are organized into layers — not alphabetically — to reflect how reasoning systems actually operate.

📊 Economic Dynamics

These concepts describe how value is created, lost, and constrained within reasoning systems.

  • 📊 Theoretical Value
  • 📊 Invisible Opportunity Cost

The gap between Theoretical Value and actual outcomes defines the economic consequence of fragmentation. If this gap is not managed through Structural Retention, the system eventually reaches Reconstruction Bankruptcy, where the cost of recovery exceeds all generated value.
